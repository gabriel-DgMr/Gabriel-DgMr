# Hi, I'm Gabriel Durango 👋

**Founder of [LIXBON](https://lixbon.com)** · Full-stack engineer based in Colombia

I build developer infrastructure for running LLMs on your own hardware. I'm the founder of [LIXBON DEV](https://github.com/LIXBON-FOUNDER), where we ship a self-hosted inference platform end to end: gateway, GPU node agent, and web, desktop, CLI and mobile clients.

## 🚀 What I'm building

**[Lixbon](https://github.com/LIXBON-FOUNDER/Lixbon)** is a self-hosted LLM platform that runs on a distributed GPU cluster.

🔌 **OpenAI-compatible API**, so any SDK, n8n or LangChain works out of the box.

🖥️ **GPU nodes over outbound WebSocket**, with no open ports, tunnels or DNS.

📊 **Per-plan usage limits** shared across every client, with one account and one history.

📱 **Four clients:** web (React), desktop (Tauri + Rust), CLI (Go) and mobile (React Native).

🤖 **Agent orchestrator and MCP server**, so Claude Code, Cursor or VS Code can drive it.
